There are no new unit or integration tests to write. The test plan focuses entirely on
**regression verification**: confirming that the existing test suite continues to pass
after the restructuring, and that all toolchain entry points work correctly from their
new locations.

## Edge cases and error paths

- [ ] Running `make build` before `go.work.sum` is committed produces a clear error, not
      a silent failure.
- [ ] Running `cd api && go test ./...` with `GOWORK=off` still resolves all dependencies
      via `api/go.mod` alone.
- [ ] `make db-migrate` with no `DB_URL` set prints a clear error from `golang-migrate`,
      not a silent success.
