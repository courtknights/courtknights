## Notes on test scope

The CI scripts in `infra/cicd/` are not Go or Angular code and are therefore not subject to the
project's standard unit/integration test frameworks. As stated in `02_architecture.md`:

> Scripts under `infra/cicd/` are not covered by the project's test suite. The CI jobs
> themselves act as their functional validation.

Test cases in this document are **functional shell tests** — runnable locally by setting the
required environment variables and invoking `make cicd-<target>` (or the script directly).
Each test case documents: the input state, the command to run, and the expected exit code and
output.
