## Scope

This feature touches only CI configuration and documentation files. There are no Go packages or Angular components to unit-test. Tests are entirely behavioral: they verify that the CI workflow responds correctly to different PR configurations.

---

## CI behavioral tests

These scenarios must be validated manually (or via a test PR) before the feature branch is merged to `main`.

### TC-001 — Task PR triggers only the fast check set

- **Setup:** open a PR from `feature/CK-64/NNN_foo` targeting `feature/CK-64/branch`.
- **Expected jobs:** `spec-ref`, `backend-cov-unit`, `frontend-cov`.
- **Not expected:** `backend-cov-full`, `adr-consistency`, `design-content-check`.

### TC-002 — Feature→main PR triggers the full check set

- **Setup:** open a PR from `feature/CK-64/branch` targeting `main`.
- **Expected jobs:** `spec-ref`, `backend-cov-full`, `frontend-cov`, `adr-consistency`.
- **Not expected:** `backend-cov-unit`, `design-content-check`.

### TC-003 — Design branch PR passes content check when only docs/specs/ is modified

- **Setup:** open a PR from `feature/CK-64/000_design` targeting `feature/CK-64/branch` with changes only under `docs/specs/`.
- **Expected:** `design-content-check` passes.

### TC-004 — Design branch PR fails content check when non-spec files are modified

- **Setup:** open a PR from `feature/CK-64/000_design` targeting `feature/CK-64/branch` with at least one change outside `docs/specs/` (e.g. `api/internal/domain/user.go`).
- **Expected:** `design-content-check` fails with an error listing the offending file.

### TC-005 — Design content check does not run on non-design branches

- **Setup:** open a PR from `feature/CK-64/001_adr-branching` targeting `feature/CK-64/branch`.
- **Expected:** `design-content-check` job is skipped (not shown or skipped state in GitHub UI).

### TC-006 — backend-cov-unit does not require Docker

- **Setup:** run `make cicd-backend-cov` with `PHASES=unit` locally without Docker running.
- **Expected:** script completes successfully (no Testcontainers spin-up attempted).

### TC-007 — backend-cov-full runs both phases

- **Setup:** run `make cicd-backend-cov` with `PHASES=all` (or default) with Docker available.
- **Expected:** both unit and integration phases execute.

## Documentation completeness checks

Review `CONTRIBUTING.md` manually against the checklist in TASK-005 done conditions.

### TC-009 — README.md quick-start is accurate

## Exclusions
