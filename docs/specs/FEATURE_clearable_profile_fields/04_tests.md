## Edge cases and error paths

- [ ] `display_name: null` → `400` (TASK-005)
- [ ] `"city": "   "` → `400`; `null` is the only way to clear (TASK-005)
- [ ] Body `[]`, `"text"`, `null` → `400` (TASK-005)
- [ ] `Content-Type: text/plain` → `415` (TASK-005)
- [ ] Unknown top-level or preference member → `400` (TASK-005)
- [ ] `{"country": null, "region": "ES-MD"}` → `400` (TASK-004)
- [ ] `{"region": "ES-MD"}` with no stored country → `400` (TASK-004)
- [ ] `{"country": "FR"}` on `ES`/`ES-MD` → region cleared (TASK-004)
- [ ] `{"country": "ES"}` on `ES`/`ES-MD` → region kept (TASK-004)
- [ ] Concurrent country change between read and write → `409` (TASK-002, TASK-005)
- [ ] `{}` → `200`, nothing written (TASK-003, TASK-004, TASK-005)
- [ ] `PUT /users/me/profile` → `405` (TASK-005)
