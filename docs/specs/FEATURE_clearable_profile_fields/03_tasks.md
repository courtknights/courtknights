### TASK-004: Manager location rules for merge patches

- **GitHub Issue:** #
- **Depends on:** TASK-003
- **Layer(s):** application
- **Description:**
  `profileManager.Update` loads the stored profile (`FindByUserID`) and applies
  the *Location rules* of `02_architecture.md`:
  - country changed or cleared and region absent → `patch.Region = Cleared`;
  - same country with region absent → region kept;
  - region with a value → validated against the effective country (patch
    country if present, otherwise stored); no effective country → wrapped
    `ErrInvalidLocation`;
  - country with a value → validated.
  `ErrProfileNotFound` and `ErrProfileConflict` are propagated wrapped.
- **Done when:**
  - [ ] Unit tests cover every row of the *Location rules* table
  - [ ] An empty patch does not call `Update` on the repository
  - [ ] `make lint` and `make test` pass
